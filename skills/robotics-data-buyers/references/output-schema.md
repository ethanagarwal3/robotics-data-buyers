# Prospect research output

Create four sheets in one Excel workbook. If necessary, use four CSV files with the same names. Include researched records only. Record unknowns explicitly and leave missing contact values blank.

## Prospects

Use one row per company. Put fields most useful for outreach first, followed by supporting detail. Include:
- Rank, company and domain.
- Purchasing evidence category and what is established.
- Footage fit and reason.
- Primary contact, current role and function: sponsor, data operations, buyer or routing contact.
- Work email, verification status, provider and check date.
- Suggested outreach angle and next qualification question.
- Missing requirements, commissioning opportunity and commercial uncertainty.
- Relevant project, buyer segment and dated reason to approach now.
- Professional profile, role evidence, company evidence and technical evidence links.
- Research date and an alternate contact or channel when useful.

Do not shorten an unconfirmed category into a confirmed-buyer label. Deliverability and person ownership are separate claims.

## Evidence

Use one row per material claim. Include an evidence ID, company, claim, source URL, publisher, publication date, access date, source type, fact versus inference and limitations. Link prospect rows to these records.

Preserve month-only dates as months or label date precision. Do not invent a publication day. Use tool call IDs for enrichment and verification when there is no public source URL.

## Dataset brief

Record the current offering: existing versus planned inventory, tasks, environments, cameras, perspective, quantity, annotations, sensor streams, licensing rights, exclusions and run scope. Separate facts, unknowns and assumptions. Keep the brief specific to this run.

## Run receipt

Include the authorized Treg cap, actual spend, unresolved holds, unused allowance and coverage. List call IDs, endpoints/providers, outcomes and charges. Count verification charges once, including when bundled with finding an email. Exclude credentials and raw personal-profile responses.

Reconcile charges with a simple sum. Distinguish Treg charges from assistant usage and other services. An unused spending allowance is not prepaid money or a refund.
